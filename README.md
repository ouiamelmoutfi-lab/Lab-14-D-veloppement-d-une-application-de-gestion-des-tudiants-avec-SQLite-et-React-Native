# Lab 14 : Développement d'une application de gestion des étudiants avec SQLite et React Native

## Objectif

Développer une application mobile de gestion des étudiants avec React Native, Expo et SQLite, permettant l'ajout, la modification, la suppression et la recherche des étudiants.

## Résultats obtenus

### 1. Interface initiale

L'application affiche un formulaire de saisie, une barre de recherche et une section de statistiques par filière.

### 2. Ajout et recherche d'un étudiant

Après l'ajout d'un étudiant, ses informations sont affichées dans la liste. La barre de recherche permet de filtrer les résultats.

### 3. Affichage des étudiants et statistiques

Ce lab nous a permis d'intégrer SQLite dans une application React Native, d'implémenter les opérations CRUD et de créer une interface dynamique avec FlatList.
